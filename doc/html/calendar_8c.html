int novas_is_leap_year ( int year,
enum novas_calendar_type calendar )

Checks if a given year is a leap year in a specific calendar.

Parameters
year[yr] The calendar year. for X BCE, it is 1 - X. For example 45 BCE is -44.
calendarThe type of calendar
Returns
TRUE (1) if the year is a leap year in the calendar, or FALSE (0) if it is not a leap year, or else -1 if the calendar is invalid (errno set to EINVAL).
